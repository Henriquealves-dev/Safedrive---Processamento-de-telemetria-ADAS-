# Safedrive---Processamento-de-telemetria-ADAS-
O objetivo deste projeto em laboratório é construir a lógica central desse sistema em Linguagem C, implementando uma calculadora de telemetria acionada por um menu. O sistema deve armazenar e processar múltiplas amostras de tempo (histórico de leituras) utilizando exclusivamente matrizes bidimensionais.
